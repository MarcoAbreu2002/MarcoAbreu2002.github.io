Security Application Suite (Python)

This project consists of a comprehensive Python-based security application designed to explore both offensive and defensive cybersecurity techniques in controlled and ethical environments.


🎯 Objectives

  • Understand network reconnaissance and attack surfaces
  • Simulate common network attacks in a controlled environment
  • Develop secure communication mechanisms
  • Analyze service logs for malicious behavior

🛠️ Implemented Features

  • Detection and listing of open ports on remote machines
  • UDP Flood (DoS) simulation using raw packets
  • TCP SYN Flood attack against selected services
  • Log analysis for HTTP, SSH, and other services
  • Syslog server integration
  • Secure client-server messaging system
  • SSH port knocking implementation with firewall rules

⚙️ Technologies Used

Python Scapy Linux Networking Cryptography
