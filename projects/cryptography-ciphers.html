Classical Cryptography Application in Python

This project focuses on the implementation and analysis of classical cryptographic ciphers using Python, with a strong emphasis on both encryption mechanisms and cryptographic attacks. Although these ciphers are no longer secure by modern standards, they play a crucial role in understanding the foundations of cybersecurity.

The application implements two well-known classical ciphers: the Affine Cipher and the Vigenère Cipher, along with multiple attack techniques used to break them.

🧱 Project Architecture

The application is modular and divided into three main components:

  • main.py – Main interface and application controller
  • Vigenere.py – Full implementation of the Vigenère cipher and attacks
  • ft-affine.py – Affine cipher implementation and cryptanalysis techniques

This modular design improves readability, maintainability, and scalability, following good software engineering practices.

🖥️ Main Application Menu

The main.py file acts as the entry point of the application, providing a unified interface to access both cipher modules.

  • Cross-platform screen clearing (Windows, Linux, macOS)
  • Interactive ASCII-based menu
  • Execution of independent cipher modules via subprocesses
  • Graceful handling of invalid input and interruptions

🔢 Affine Cipher Implementation

The Affine cipher is a monoalphabetic substitution cipher based on modular arithmetic. It uses the formula: 

C = (A × P + B) mod 26

Where A and B are keys and A must be coprime with 26 to ensure successful decryption.

Implemented Features

  • Encryption and decryption using modular arithmetic
  • Automatic calculation of modular inverse
  • Support for non-alphabetic characters

Cryptographic Attacks

  • Brute-force attack testing all valid key combinations
  • Dictionary attack using real Portuguese wordlists
  • Known-plaintext attack to recover the encryption key

These attacks clearly demonstrate the weakness of monoalphabetic ciphers and the dangers of small key spaces.

🔤 Vigenère Cipher Implementation

The Vigenère cipher is a polyalphabetic substitution cipher that uses a repeating keyword to encrypt text. It was historically considered secure but is vulnerable to modern cryptanalysis techniques.

Key Features

  • Dynamic generation of the Vigenère table
  • Encryption and decryption modes
  • Step-by-step visualization of the encryption process
  • Input validation for safe and controlled execution

Educational Step-by-Step Mode

One of the most valuable aspects of this implementation is the step-by-step mode, which visually highlights:

  • The plaintext character
  • The key character
  • The resulting encrypted character
  • The corresponding row and column in the Vigenère table

🧨 Attacks Against the Vigenère Cipher

  • Brute-force attack: Generates all possible keys up to a defined length and tests decrypted output against a dictionary.
  • Dictionary-based validation: Uses linguistic properties to drastically reduce false positives.
  • Known-plaintext attack: Recovers the encryption key by exploiting the mathematical relationship between plaintext and ciphertext.

These attacks highlight an essential cybersecurity principle: security must rely on strong keys and algorithms, not on secrecy or obscurity.

📚 Cybersecurity Concepts Demonstrated

  • Classical cryptography fundamentals
  • Key management and key space analysis
  • Modular arithmetic and inverses
  • Brute-force and dictionary attacks
  • Known-plaintext attack scenarios
  • Secure and modular software design

🧠 Conclusion

This project serves as both a technical and educational demonstration of classical cryptography and its weaknesses. By implementing not only encryption algorithms but also practical attack techniques, it reinforces a deep understanding of why modern cryptographic standards are necessary.
